# Polski C1 — тренажёр польского языка

Тренажёр польского уровня C1 в одном HTML-файле. Интерфейс на русском. Работает как артефакт Claude (с синхронизацией прогресса между устройствами) и как обычная страница в браузере.

**Открыть тренажёр:** https://arqw4900-stack.github.io/polish-c1-trainer/ (телефон и компьютер, без регистрации; прогресс хранится в браузере)

Версия в Claude с синхронизацией между устройствами (приватная): https://claude.ai/artifact/RKK5HVE2a1JBqcw3knmcyx

## Что внутри

- **Слова** — 3544 слова и выражения в 13 темах (по 256–314 в каждой): работа, деньги и бизнес, общество и политика, право и учреждения, наука и технологии, здоровье, характер и эмоции, природа и экология, образование, культура и медиа, путешествия и город, отдельная тема **Język potoczny** (разговорные слова, сленг, идиомы, пословицы) и **Сложная лексика C2** — книжные и публицистические слова (*bagatelizować, niefrasobliwy, ambiwalencja*), латинизмы (*de facto, notabene*) и крылатые выражения (*syzyfowa praca, pyrrusowe zwycięstwo*). В каждой из 12 тематических тем есть и трудные слова уровня C1+: юридические и экономические термины, книжная лексика, идиомы (*piastować, wokanda, zachowek, karencja, splątanie kwantowe, zgryzota, kręcić lody*). У каждого слова — перевод и пример. Интервальные повторения (1 → 2 → 4 → 7 → 14 … дней), три типа карточек: выбор перевода, перевод на польский, ввод с клавиатуры.
- **Ввод польских букв** — ответ без диакритики (`zrodlo` вместо `źródło`) засчитывается как «почти» с подсветкой нужных букв; под полем есть кнопки ą ć ę ł ń ó ś ź ż.
- **Грамматика** — 13 тем C1: вид глагола, глаголы движения с приставками, условное наклонение, страдательный залог, причастия и деепричастия, трудные случаи родительного, творительный, дательный, звательный и вежливые формы, числительные, местоимения, мужско-личный род, союзы. Правило, таблица, примеры и 163 упражнения с объяснением «Почему» к каждому.
- **Чтение** — 10 коротких историй C1, перевод выражений по нажатию, 3 вопроса на понимание к каждой.
- **Письма** — 12 образцов: официальные (list motywacyjny, reklamacja, заявление в urząd, podanie do dziekana, расторжение аренды), полуофициальные (преподавателю, коллеге, начальнице) и неформальные (подруге, приглашение, поздравление, извинение). К каждому — разбор структуры по частям, формулы обращения и завершения по регистру, полезные фразы с переводом и упражнение.
- **Панда Клуска** — живёт на главной: довольна и прыгает, если сегодня сделан хотя бы один урок (законченное занятие, тест или история), ждёт, если урока ещё нет, грустит, если вчера пропустили, и плачет под тучкой после нескольких пропущенных дней. Говорит по-польски с переводом; под ней — неделя с отпечатками лап за дни с уроками.
- **Прогресс** — серия дней, график ответов, прогноз повторений, освоенные темы грамматики, истории и письма, экспорт и импорт прогресса в JSON.

## Как запустить

- **В браузере:** открыть ссылку на GitHub Pages выше. Прогресс хранится в этом браузере; переносить его можно через «Настройки → Резервная копия».
- **Как приложение на телефоне:** открыть ссылку на GitHub Pages → на iPhone «Поделиться» → «На экран „Домой“», на Android меню браузера → «Установить приложение» (или кнопка в «Настройках»). После первого открытия тренажёр работает без интернета: это делают `manifest.webmanifest`, `sw.js` и иконки `icon-*.png`. В артефакте Claude они не используются.
- **В Claude:** открыть ссылку на артефакт (нужен доступ к нему). Прогресс хранится в аккаунте и одинаков на телефоне и компьютере.
- **Локально:** открыть `index.html` в браузере.

## Как устроен проект

`index.html` — готовое приложение: стили, данные и логика, без библиотек (только Google Fonts). Его собирает `src/build.py` из текстовых файлов, которые удобно править и проверять:

| Что | Где |
|---|---|
| Словарь | `src/words/NN_тема.txt` — строка `польское \| русский перевод \| пример`, первая строка `# Тема \| Temat` |
| Грамматика | `src/grammar.txt` — `rule:`, `table:`/`row:`, `e:` пример `;;` перевод, `tip:`, `q:` упражнение |
| Истории | `src/stories.txt` — `p:` абзац, `g:` слово в тексте `=` перевод, `q:` вопрос `\|` верный `\|` неверные |
| Письма | `src/letters.txt` — `b:` часть письма `\|` текст `\|` разбор `\|` выравнивание, `r:` обращения и завершения, `f:` фразы, `q:` упражнения |
| Интерфейс и логика | `src/app.html` (вместо `/*@DATA@*/` подставляются данные) |

Формат упражнения (грамматика и письма): `предложение с ___|ответ|неверный|неверный|неверный##объяснение`.

```bash
python src/build.py      # собрать index.html
python tools/check.py    # проверить данные
```

`tools/check.py` проверяет: в каждой теме ≥200 слов, нет повторов польских слов и одинаковых русских переводов, у упражнений есть пропуск, уникальные варианты и объяснение, слова-подсказки историй есть в тексте, письма заполнены полностью.

В коде: состояние `S = {w, log, gr, rd, lt, set}` — слова, ответы по дням, лучшие результаты по грамматике, истории, письма и настройки. `merge()` сливает копии с разных устройств: слова — по времени последнего ответа, результаты — по лучшему, сброс — через метку `rs`. `norm()` и `plain()` сравнивают ответ с учётом и без учёта польских букв.

## Публикация в Claude

Артефакт объявляет возможности `db` (прогресс в `data/users/<id>/progress`), `user` (id пользователя) и `downloads` (экспорт файла). Обновлять — публикацией `index.html` с `url` артефакта.

## Заметки

- Проверка носителем языка приветствуется: правки удобнее всего вносить в `src/*.txt` и пересобирать `index.html`.
- В артефакте файлы скачиваются только через capability `downloads`; на GitHub Pages и локально — обычной загрузкой. Код поддерживает оба случая.
- Claude ставит `data-theme` на `<html>`, поэтому свои элементы этим атрибутом не помечать (у тем — `data-topic`).
- `\b` в регулярных выражениях JavaScript не знает польских букв — для границ слов используется `\p{L}` с флагом `u`.
